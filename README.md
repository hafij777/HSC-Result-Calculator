# HSC Result Calculator

A simple Python-based Result Calculator for Bangladesh HSC students.

## Features

- Takes Registration Number and Roll Number
- Supports Science, Commerce, and Arts groups
- Different mark structures for different subjects (MCQ, CQ, Practical)
- Automatic grade calculation (Golden A+, A+, A, A-, B, C, D, Fail)
- Input validation (digit limit + marks range check)
- Case-insensitive group input

## Subjects Covered

**Common Subjects:**
- Bangla 1st & 2nd
- English 1st & 2nd
- ICT

**Science Group:**
- Physics, Chemistry, Biology, Higher Math (1st & 2nd Paper)

**Commerce Group:**
- Accounting, Business, Finance (1st & 2nd Paper)

**Arts Group:**
- Civics, Logic (1st & 2nd Paper)

## How to Run

1. Make sure Python is installed
2. Run the file:
```bash
python result_calculator.py# HSC Result Calculator
